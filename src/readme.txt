A lightweight consent management plugin to help your WordPress site comply with GDPR, CCPA, and other privacy regulations.

== Description ==

Consent Pilot helps you implement cookie consent and manage user privacy preferences in compliance with global data protection laws such as GDPR, CCPA, LGPD, and ePrivacy.

Features include:

* Customizable cookie consent banner
* Block scripts and cookies until consent is given
* Consent categories (necessary, functional, analytics, marketing)
* Easy integration with Google Analytics, Tag Manager, Facebook Pixel, etc.
* Consent log and export options
* Multilingual support (WPML, Polylang compatible)
* Lightweight and performance-friendly

Perfect for site owners who want a simple, compliant, and customizable way to manage user consent.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/wp-consent-manager` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the "Plugins" screen in WordPress.
3. Go to **Settings > Consent Manager** to configure your banner and preferences.
4. Add your tracking scripts under the correct consent categories.

== Frequently Asked Questions ==

= Does this plugin set cookies by itself? =  
No. Consent Pilot only manages cookies and scripts set by other plugins, themes, or external services.

= Is it GDPR and CCPA compliant? =  
This plugin provides the technical tools to implement consent. Legal compliance also depends on your specific website setup and legal advice.

= Can I customize the banner design? =  
Yes, you can adjust colors, text, and positions directly in the settings.
